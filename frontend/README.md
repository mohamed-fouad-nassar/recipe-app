# Frontend

## 🏗️ Project Architecture (Angular)

```bash
frontend/src/app/
 ├── core/        (auth, interceptors)
 ├── shared/      (reusable components)
 ├── features/
 │    ├── auth/
 │    ├── recipes/
 │    ├── profile/
```

## 📦 Getting Started

This project was generated using [Angular CLI](https://github.com/angular/angular-cli) version 21.2.1.

### 1. Install dependencies

```bash
cd frontend
npm install
```

---

### 2. Run the app

```bash
ng serve
```
